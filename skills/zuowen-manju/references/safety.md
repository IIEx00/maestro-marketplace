# 安全与合规

本 skill 处理的是未成年人写的作文，分镜里会出现儿童形象。以下为硬性约束。

## 一、儿童形象：强制卡通化

**所有** `image_prompt_en` 必须包含以下 safety tags（校验脚本会检查）：

```
cartoon child character, stylized animation, non-photorealistic, child-safe
```

**禁止词**（校验脚本会拦截）：

```
photorealistic, photoreal, realistic photo, real person, hyperrealistic,
photo of a child, lifelike, DSLR, 8k photo
```

原因：写实风格的儿童形象存在被滥用风险，且平台对 AI 生成的儿童写实图审核严格。
卡通化既安全，也符合怀旧动画的调性。

## 二、隐私脱敏

**不进 prompt 的内容**：

- 真实姓名（学生、家长、老师、同学）
- 学校名称、班级、学号
- 家庭住址、小区名、门牌号
- 电话号码、身份证号
- 具体的车牌号、店名

**处理方式**：

- 人物统一用 `CHAR_A`、`CHAR_B`、`CHAR_C` 代号
- 学校统称 `a Chinese primary school` / `a Chinese middle school`
- 地点统称 `a small town in China` / `the family apartment`

**原文里保留**：旁白 `captions` 直接引用原文时，姓名可以保留（那是原作文内容，
不是 prompt）。但如果原文出现完整地址、电话，转录稿里也要打码：
`138****5678`、`XX市XX区XX路`。

## 三、题材红线

出现以下内容时**停下来问用户**，不要直接做：

- 涉及自杀、自伤、家庭暴力
- 涉及未成年人的亲密关系描写
- 涉及真实社会事件的负面细节
- 明显的成人向内容被塞进儿童作文（可能不是小孩写的）

这些不是「改进一下就能做」的问题，需要用户判断是否适合传播。

## 四、L2 改编的额外约束

L2 允许加戏，但：

- 不许增加死亡情节
- 不许增加暴力冲突（可以让妈妈「瞪眼」，不许「打人」）
- 不许增加爱情线
- 不许丑化老师、家长（可以夸张，不能恶意）

## 五、平台适配

发布到不同平台时的注意事项：

| 平台 | 注意 |
|---|---|
| 抖音 / 视频号 | 儿童出镜内容需注意未成年人保护规则，卡通化规避了大部分风险 |
| 小红书 | 图文形式发布分镜更稳妥 |
| B 站 | 相对宽松，但标题别用「熊孩子」这类标签 |

## 六、AI 生成标识

如果用户要发布，建议在文案里注明「AI 漫剧改编」。
部分平台（抖音、小红书）对 AI 生成内容有标识要求。

## 七、校验脚本检查项

`scripts/validate_storyboard.py` 会硬性检查：

1. 每个 `image_prompt_en` 是否包含 4 个 safety tags
2. 是否出现禁止词
3. 是否出现疑似真实姓名（2-3 个汉字 + 「同学」「老师」「妈妈」以外的专名，
   用启发式规则，有误报可能，需人工复核）
4. 是否出现学校/地址类关键词

校验不过不许交付。
