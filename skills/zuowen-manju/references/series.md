# 系列：多篇做成一个账号

「一篇一次」指的是**产出单位** —— 每篇独立转录、独立分镜、独立校验。
但对外发布时，几篇往往合成一个**账号**，这时需要额外的一套约定。

## 核心原则：共用视觉，不共用设定

| 共用 | 不共用 |
|---|---|
| 人物定妆图（同一套造型模板） | 人物**身份**（是不是同一个"我"、同一个弟弟） |
| 作业本外壳（`pencil-notebook` 的 P01/P08） | 人物**年龄、性别** |
| 画风家族（上美影系六选一） | 各篇的**题材画风** |
| 旁白音色、字幕样式、老电视后期 | 各篇的**梗类型** |

**为什么这么分**：画风模板是账号的识别资产，必须统一；
人物设定是叙事事实，跨篇统一就是造假 —— 观众或家长会发现「这不是同一个孩子」。

> 实测：多篇来自不同的孩子。做法是**各篇共用同一套人物定妆图**，
> 但每篇的 `character_index` 各写各的 —— 第一篇的弟弟 3 岁、第二篇 5 岁、
> 第二篇的「我」是哥哥（原文有「哥哥，哥哥」为证）、第一篇的「我」是姐姐还是哥哥原文没说。
> 视觉统一，设定不越界。

## 跨篇复用定妆图

定妆图只有一套，放在**第一个出图的篇目**的 `images/` 里，其他篇目拷贝过去：

```bash
cp outputs/篇一/images/CHAR_A.png outputs/篇二/images/CHAR_A.png
```

各篇的 `character_index` 里 `CHAR_A` 指的是**该篇**的角色，文件名可以复用，
但 `appearance_en` 各自的字符串可以不同（年龄、性别）。

`batch_images.py` 按文件内容哈希缓存上传，同一张图在多篇里当参考图**只上传一次**。

## 作业本外壳

系列里每篇的 P01（标题特写）和 P08（末段特写）都用 `pencil-notebook` 画风，
在 `storyboard.json` 里给这两格加 `style_prefix_override`：

```json
{
  "shot_id": "P01",
  "style_prefix_override": "pencil sketch illustration on Chinese school exercise-book paper, ...",
  "image_prompt_en": "pencil sketch illustration on ..., extreme close-up of ..."
}
```

校验脚本会认这个字段（该格改用覆盖值校验），其余格仍跟随全篇的 `style_prefix`。

**为什么外壳要用铅笔本而不是主画风**：`pencil-notebook` 的前缀里自带
`red teacher pen marks as accent color`，而红笔批改正是应试作文卷面反复出现的元素
（扣分、修正栏、老师的圈画）。它天然就是账号的第二个识别标记。

## 选题与钩子编排

一个系列里每篇的**梗类型要错开**，否则观众会觉得"又是同一个套路"。

| 梗类型 | 素材来源 | 钩子句式 |
|---|---|---|
| 错别字 | 写错的字 | 「老师圈出来的错别字，我一个字没改」 |
| 拼音注音 | 不会写的字标拼音 | 「不认识的字，他拼音标在旁边」 |
| 病句 | 成分残缺、搭配不当 | 「'仰头上脸上都是水珠'，我照着画了」 |
| 事件 | 最有戏剧性的那一幕 | 「我弟哭了，原因是他把玩具熊扔进了鱼缸」 |

**发布顺序**：先发画面自带萌点的那篇（拉新），再发情感最重的那篇（留存）。

## 系列登记

跨篇复用的人物，在各篇的 `source.md` 里记一笔来源。例：

```
## 系列信息
- 本篇属于「三个孩子的作文」系列
- CHAR_A 造型沿用第一篇已出的定妆图（不同孩子，同一套模板）
- 画风：赛璐璐，与第一篇同系
```

这样任何时候翻出任意一篇，都知道它跟其他篇的关系。

## 系列的成本纪律

- **定妆图只出一套**，全系列复用 —— 这是系列最大的省钱点
- **外壳可以只出一次**，后续篇目用 `edit` 局部改
- 每篇的**内容格**才是真开销，按 `production.json` 逐篇估价
- 余额不够时**先出系列里最有代表性的一篇**，别每篇出半套
