# 读图与转录规则

## 一、能读什么

| 来源 | 处理 |
|---|---|
| 手机拍照（有阴影、倾斜） | 直接读，不要先转正，模型能处理 |
| 扫描件 / 打印机打印 | 直接读 |
| 作业本方格纸 | 按格子逐行读，注意跨格的换行 |
| 老师红笔批改 | 记入 `source.md` 的「批注」小节，不混进正文 |
| 家长签字 / 日期 | 同上，记入「批注」小节 |

## 二、转录规则

1. **逐字转录**，不修正、不补充、不顺句。
2. 错别字照抄原样。例如原文「我很辛福」→ 转录 `我很辛福`，
   在 `typos` 里登记：`{"wrong": "辛福", "right": "幸福", "type": "typo"}`。
3. 拼音代替字（他不会写「蝴蝶」写成 `hu die`）照抄，登记为
   `{"wrong": "hu die", "right": "蝴蝶", "type": "pinyin"}`。
   `right` 填推测的本字（无法判断时留空，脚本会提示警告）。
4. 涂改痕迹：
   - 划掉的词：保留并标 `[划掉：XXX]`
   - 补写的词：保留并标 `[补：XXX]`
   - 大面积涂黑：标 `[涂黑]`，不要猜内容
5. 分段按原文分段，保留段落数量。
6. 标点错误照抄（如全篇逗号到底），在 `typos` 之外单列 `punctuation_issues`。
7. 字数统计写进 `source.md`。

## 三、认不出怎么办

**绝不猜。**

- 单字认不出 → 写 `？`，例如 `我的？妈很辛苦`
- 整句认不出 → 写 `[？整句无法辨认]`
- 全部收进待确认清单：

```markdown
## 待确认清单
1. 第 2 段第 3 行：「我的？妈」——是「妈妈」吗？
2. 第 4 段末：「[？整句无法辨认]」——请补拍该区域特写
```

交付时先问清单，用户确认后再定稿。如果用户说「就按你理解的来」，才允许填，
并在 `source.md` 里标 `[已按用户授权补全]`。

**例外**：若无法辨认的内容不影响分镜（如页眉的班级名），可以先产出，
在交付里标注「该处未用于分镜」，不必阻塞。

## 四、判断年级与题材

**年级**（看字迹 + 字数 + 用词，不绝对）：

| 线索 | 推断 |
|---|---|
| 铅笔、方格大、有拼音、200-400 字 | 小学低年级 |
| 钢笔/中性笔、400-600 字、比喻堆砌 | 小学高年级 / 小升初 |
| 600-800 字、有结构意识、开头点题 | 初中 / 中考 |
| 800 字以上、议论成分、成语密度高 | 高中 / 高考 |

考试字数的官方口径见 `exam-requirements.md`：**不是全国统一**——中考多数地区
「不少于 600 字」，但浙江、广东部分地区是 500 字；小升初常见 400-600 字；
高考全国卷「不少于 800 字」，北京大作文 700 字。**以卷面题面为准**。

**题材**（决定画风推荐和分镜节奏）：

- `写人` — 有明确人物，多为「我的XX」
- `写事` — 有起因经过结果
- `写景` — 按空间或时间顺序描写
- `状物` — 围绕一个物件
- `想象` — 假如/未来/童话
- `议论` — 观点+论据（高中常见）
- `诗歌` — 分行排列、有押韵或意象跳跃（**考试通常「诗歌除外」，但用户可能主动发来**）

判断结果写进 `source.genre` 与 `source.grade_guess`，并在对话里说明是推测。

**如果卷面上有题面**（很多作文本会印题目要求），顺便识别四要素：
题目 / 文体限制 / 字数要求 / 禁忌项，记入 `source.md`。
这四项的判读方法见 `exam-requirements.md` 第一节。

### 诗歌的转录差异

诗歌不是「段落」，转录时：

1. **按行保留**，一行一行抄，不要合并成一段
2. **保留空行**（诗节分隔），在 `source.md` 里用空行表示
3. 标点同样照抄，诗歌常省略句号，不要补
4. `typos` 仍按同样规则登记
5. 在 `source.md` 头部标注 `体裁：诗歌`

判断是否为诗歌：看是否**分行断句**且**行末不接下一行读不通**。散文有时也分行，
但一行是一句完整的话；诗歌一行往往只是一个意象。

无法确定时**问用户一句**：「这篇是诗还是分行写的散文？」——这是少数值得打断的情况。

## 五、转录稿格式

```markdown
# 转录稿 · 《我的妈妈》

- 推断年级：小学三年级
- 题材：写人
- 字数：386 字
- 转录时间：2026-11-12
- 卷面题面：（如有）文体不限，诗歌除外，不少于 600 字

## 正文

我的妈妈很辛福，因为她有一个我。
每天早上六点，妈妈就起床给我做早饭……

## 错别字登记

| 原文 | 正确 | 位置 |
|---|---|---|
| 辛福 | 幸福 | 第 1 段第 1 行 |

## 标点问题

- 第 2 段全段逗号到底，无句号

## 批注

- 老师红笔：「结尾太仓促，建议补充细节」
- 家长签字：已阅

## 待确认清单

（无）
```

## 多页与缺页

一篇作文常常横跨两页，甚至三页。**先判断是「缺页」还是「页缝断句」**，两者的处理完全不同：

| 情况 | 判据 | 处理 |
|---|---|---|
| **页缝断句** | 前页末尾是未完成的半句，后页开头正好接上 | 直接接成一句，转录为一个完整句子 |
| **真的缺页** | 前页末尾句子已完整，但后页开头跳到了另一件事 | 记进待确认清单，标注缺了哪一段 |
| **孩子本来就没写** | 日期跳跃（如 10/23 → 10/27），中间没有正文 | **不是缺页**，是孩子的观察节奏，照实转录 |

- 接页缝时**以纸上的字为准**，不要自己补字。跨页的那半句，
  拼起来不通顺也照抄，通顺才说明接对了。
- 判定缺页前，先确认**不是页码顺序弄反**。拍到的两张可能不是第 1 页和第 2 页。
- 缺页会直接影响拆格：缺了哪一段，中间的镜头就补不上。
  在待确认清单里写清楚「缺哪一天 / 哪一段」，用户补拍后直接接上。

## 字认不出的时候

- 一个字认不出，用 `？` 占位，**不要猜**。
- 但要尽量缩小范围：把该字所在的**行**单独裁出来放大，
  结合上下文、笔画、是否被折痕压住，多半能认出来。
- 真的认不出，就在待确认清单里写「第几段第几个字 + 候选 + 为什么不确定」，
  让用户一句话就能确认。
- 折痕压住的字尤其容易误判 —— 压住一半的字看起来像另一个字。
  这时候**先问用户，别按上下文补**（实测有一次把「塌」看成了别的字）。
