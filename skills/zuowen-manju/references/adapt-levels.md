# 三档处理细则

默认 **L0**。用户没说要改，就按 L0 走，不要先问。

## L0 原汁原味（默认）

**原则：一个标点都不动。**

- 错别字保留，且要出现在画面里当梗
- 病句保留
- 标点错误保留
- 段落顺序不动
- 分镜只做「视觉化」，不做「文学化」

**错别字怎么当梗**（这是 L0 的核心价值）：

| 原文 | 分镜处理 |
|---|---|
| 「我很辛福」 | P01 作业本特写，红圈圈住「辛福」 |
| 「妈妈像一只老虎一样爱我」 | P04 画面一半是妈妈温柔脸、一半是老虎剪影，旁白原句 |
| 「我的爸爸是个大忙人，他每天都很忙」 | P05 重复啰嗦原句直接做旁白，画面是爸爸在不同场景重复出现 |
| 拼音写不出 | P03 画面里作业本上就是拼音，不加字幕修正 |

**禁止**：L0 下不许「顺手改得更通顺」。用户要的就是那股原味。

## L1 轻度润色

**原则：只修硬伤，不动内容。**

允许：
- 改错别字
- 修标点（逗号到底 → 分句）
- 补明显的漏字（「我妈妈」→「我的妈妈」）

禁止：
- 改句式
- 加修辞
- 调段落顺序
- 补情节

**输出差异**：`source.md` 里给出 diff 式对照表（原文｜改后｜原因），
每格同时填 `source_text`（改后）与 `source_text_original`（原文），
校验脚本对 L1/L2 强制要求后者。

## L2 改编

**原则：为传播服务，但要保住原文的骨架。**

允许：
- 加冲突（把「妈妈做了饭」扩成「妈妈忘放盐，我硬着头皮吃完」）
- 加反转（结尾从平铺改成回扣开头）
- 压缩铺垫，放大高潮
- 加一句儿童视角的「金句」旁白

必须：
- 保留原文的人物关系与核心事件
- 在 `source.md` 里列出「改编点」，逐条说明改了什么
- 对话里明确告诉用户「这是改编版，不是原文」

**禁止**：L2 下不许把儿童作文改成成人向内容、不许加死亡/暴力/爱情线。

## 档位切换

用户中途改主意很常见：

- 「还是原样吧」→ 回 L0，重出分镜
- 「帮我改通顺点」→ 去 L1
- 「不够抓人，加点戏」→ 去 L2

切换时在对话里说明「已从 X 切到 Y，改动的是这几处」。

## 档位与画风的关系

- L0 建议配 `pencil-notebook` 或 `shangmei-ink`，突出「这是真作业本」
- L1 建议配 `shangmei-ink` / `shangmei-cel` / `picturebook-cn`
- L2 建议配 `shangmei-cel` / `shangmei-papercut`，重彩更适合戏剧化
