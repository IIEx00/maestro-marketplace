# 准入判定：这是不是中小学生写的应试作文

本 skill 只处理**中小学生手写应试作文**。判定错了，后面全部白做，还可能把成人内容、
网络小说、AI 生成文本当儿童作文处理，产生很不合适的输出。

因此**每篇来稿都要先判定，并把判定结果和证据写进 `storyboard.json`**。

## 一、判定结果只有三种

| 结果 | 含义 | 后续动作 |
|---|---|---|
| `student_essay` | 判定为学生应试作文 | 正常走完整流程 |
| `user_confirmed` | 判定存疑，但用户确认过 | 正常走完整流程 |
| `rejected` | 判定不是学生作文 | 停止，说明原因并给替代方案 |

`rejected` 不产出 `storyboard.json`。前两种必须填 `meta.source_verdict` 与
`meta.source_signals`，校验脚本会拦。

## 二、强信号（判定依据）

满足 **任意 2 条** 且**无反证** → `student_essay`。

| 信号 | 怎么判断 | 写进 signals 的写法 |
|---|---|---|
| 学生用纸 | 方格作文纸、横线作业本、试卷答题卡、带「班级姓名」栏 | `方格作文纸` |
| 老师批改 | 红笔分数、评语、「优/良」、圈出错别字、波浪线 | `老师红笔批改+分数` |
| 手写稚嫩 | 字迹大小不均、笔画不连贯、有涂改、有橡皮擦痕 | `手写稚嫩有涂改` |
| 学生用笔 | 铅笔（低年级）、中性笔、钢笔 | `铅笔书写` |

**老师批改是最强的单条信号。** 有红笔批改 + 任意另一条，基本可以确认。

## 三、弱信号（只能辅助，不能单独成立）

- 有标题、分段
- 口语化表达、比喻朴素
- 儿童视角（「妈妈说……」「我的同桌……」）
- 题材是校园、家庭、亲人、朋友
- 存在拼音替字
- 字数落在对应学段区间（见 `exam-requirements.md`）

**只有弱信号时 → `uncertain`**，必须问用户，不能自行判定通过。

## 四、反证（出现任意一条即 `rejected`）

| 反证 | 说明 |
|---|---|
| 印刷体 / 打字 / 电子文档截图 | 不是手写，学生应试作文是手写的 |
| 出版排版 | 有页码、章号、书眉、目录 |
| 成人化表达 | 抽象思辨、专业术语、议论层层递进、罕见的成语密度 |
| AI 生成痕迹 | 工整排比、每段总结句、「不仅…而且…」「首先其次最后」机械罗列 |
| 网络小说格式 | 章节标题密集、对话占大半、有「第 X 章」 |
| 年级与内容矛盾 | 稚嫩笔迹却写 2000 字学术议论；一年级笔迹写专业内容 |

反证是**一票否决**。不要因为「字写得像小孩」就忽略成人内容——**内容优先于笔迹**。

## 五、不确定时怎么问

只问一句，不要连环追问：

> 这篇看起来不像典型的学生手写作文（没有方格纸和老师批改，字迹也比较成熟）。
> 确认是孩子写的吗？确认的话我按学生作文处理。

用户确认后 → `source_verdict = "user_confirmed"`，`source_signals` 里补一条
`用户确认`。

用户否认或说不清 → `rejected`。

## 六、拒绝时怎么说

给原因 + 给去处，不要只是「不行」：

> 这篇不符合学生应试作文的特征（是印刷体、无批改痕迹），看起来更像已排版的作品。
> 本 skill 只处理手写学生作文。如果是小说或散文，可以用 `xiaoshuojubenzhuanfenjing`；
> 如果是要做成短视频推文，用 `xiaoshuozhuantuiwenfenjing`。

## 七、记录格式

写进 `storyboard.json`：

```json
"meta": {
  "source_verdict": "student_essay",
  "source_signals": ["方格作文纸", "老师红笔批改+分数", "手写稚嫩有涂改"],
  "grade_confidence": "high"
}
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `source_verdict` | `student_essay` / `user_confirmed` | 拒稿不产出文件 |
| `source_signals` | 字符串数组，至少 2 条 | 必须是上面表格里的信号 |
| `grade_confidence` | `high` / `medium` / `low` | 学段判断的置信度 |

**`source_signals` 至少 2 条**，且不能只有弱信号。校验脚本会检查条数与内容。

## 八、常见误判

| 情况 | 正确判断 | 原因 |
|---|---|---|
| 家长帮孩子抄一遍，字迹工整 | `uncertain`，问一句 | 是学生作文，但不是学生手迹 |
| 培训机构打印的范文 | `rejected` | 印刷体，且不是考生作答 |
| 孩子写的诗 | `student_essay` | 诗歌分支处理 |
| 低年级写话（50-100 字） | `student_essay` | 学段是小学低年级 |
| 高考满分作文印刷本 | `rejected` | 出版排版 |
| AI 生成的「小学生作文」 | `rejected` | 有 AI 痕迹，无手写与批改 |
