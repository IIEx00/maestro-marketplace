# 分镜拆解规则

## 一、格数

| 格数 | 何时用 |
|---|---|
| 8 格（默认） | 一篇作文，出图快，适合抖音/视频号 |
| 16 格 | 用户说「详细点」「多来几张」「要完整」 |
| 4-6 格 | 作文很短（<300 字）或用户说「精简」 |

超过 16 格必须问用户，不要自作主张。

## 二、8 格的骨架

| 格 | 内容 | 说明 |
|---|---|---|
| P01 | 作业本特写 | 钩子。方格纸、字迹、红笔批改，**必须是第一格**（校验脚本硬性拦截） |
| P02 | 作文标题 / 开头句画面化 | 标题与首句在这里落地，不占用 P01 |
| P03-P06 | 正文主体 | 按起承转合切，一段一格或两格 |
| P07 | 情绪高点 / 结尾转折 | 原文最动人的那句 |
| P08 | 作业本收尾 / 老师批语 | 闭环，回到纸面 |

若作文很短、用 4-6 格：保留 P01 与末尾收尾格，中间压缩。
若 16 格：在 P03-P06 之间各拆两张，其余不变。

## 三、每格怎么切

**一段一个画面，不要旁白配空镜。**

判断标准：如果这一格的画面去掉旁白就看不懂，说明切错了。

错误示例：
- ❌ 旁白「妈妈很辛苦」，画面是空房间
- ✅ 旁白「妈妈很辛苦」，画面是妈妈在深夜厨房洗碗，背影，灯只有一盏

## 四、景别

| 缩写 | 中文 | 用在 |
|---|---|---|
| ELS | 大远景 | 环境交代、开头 |
| LS | 远景 | 人物在环境中 |
| MS | 中景 | 日常对话、动作 |
| CU | 近景 | 表情、情绪 |
| ECU | 特写 | 关键物件（作业本、红笔、错别字） |

8 格及 16 格都必须至少 1 个 ECU（给作业本或错别字），否则怀旧感出不来。
4-6 格时 P01 本身就是 ECU，已满足。

## 五、构图与机位

- 儿童视角：多用**低机位仰拍**，让大人的世界显得高大
- 回忆感：可加 `slightly tilted frame, vintage camera lens` 但不要每格都加
- 怀旧片：可加 `4:3 aspect ratio, subtle film grain` 统一在 style_prefix 里

## 六、旁白与对白

- 旁白（`captions`）：**直接引用原文**，L0 下错别字保留
- 对白（`dialogue`）：只有原文确实有引号对话时才写，不要编造
- 内心独白：用 `captions` 表达，标注 `[内心]`

**旁白长度**：单格不超过 30 字。原文长句要断开分到相邻格，但**不能改字**——
在断句处直接切，例如：

原文：「妈妈每天早上六点起床给我做饭然后送我上学再去上班」
→ P03 旁白「妈妈每天早上六点起床给我做饭」
→ P04 旁白「然后送我上学再去上班」

## 七、错别字梗的落点

L0 下，错别字只在两种位置出现：

1. **P01 或 P08 的作业本特写**里，红笔圈出
2. **与该句对应的那一格**，画面上出现手写原文

其余格子不要在画面上堆错字，会显得刻意。

## 八、画幅

| 场景 | 比例 |
|---|---|
| 8090 上美影风格 | 4:3 |
| 作业本 / 绘本 | 3:4 |
| 短视频平台（用户要求） | 9:16 |
| 横屏放映 | 16:9 |
| 方图（部分平台预览） | 1:1 |

默认按画风预设走，用户明确要竖屏才改 9:16。改比例时全篇统一。

## 九、时长（短剧出口才需要）

如果用户要「视频版」，每格补 `duration`：

- 静态漫剧：每格 3-5 秒（Ken Burns 推拉）
- 短剧：每格 2-4 秒，动作格可到 6 秒
- 总时长按格数折算：8 格控制在 30-45 秒，16 格控制在 60-90 秒

## 十、自检清单

产出前逐条过：

- [ ] P01 是作业本特写吗
- [ ] 每格都有 `source_text` 能对回原文吗
- [ ] 有没有旁白配空镜的格子
- [ ] 至少 1 个 ECU 吗
- [ ] 错别字梗在正确的位置吗
- [ ] 全篇 style_prefix 一致吗
- [ ] 画幅统一吗
- [ ] 每格旁白 ≤ 30 字吗
